Installer format

When the verified release is published, it will be an NSIS .exe installer — not the retired MSI installer.

Verify the installer

The release will include SHA256SUMS.txt and a Minisign .sig file alongside the NSIS installer. Compare the installer SHA-256 with the matching checksum before running it.

This beta is not code signed yet. Windows may show a publisher or reputation warning; do not bypass a warning for a file that is not accompanied by the release checksum and signature.

Availability
