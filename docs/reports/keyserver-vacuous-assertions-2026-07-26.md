**TOP 5 I WOULD FIX FIRST**

1. `test/integration/prekey-bundle.test.ts:464` is the clearest false-green shape: an empty extraction satisfies the uniqueness assertion. This is authentication/replay/quota-adjacent and can hide a total failure to pop OPKs.
2. `test/integration/control-inbox.test.ts:113` should prove the row existed before deleting it. Without that, the replay receipt path can look correct while enqueue never happened.
3. `test/integration/prekey-bundle.test.ts:175` is the same replay-receipt problem on replenish: prove OPK `700` exists before simulating consumption.
4. `test/integration/prekey-bundle.test.ts:429` checks a stale refusal but not the no-consume property named in the test. A stale request that burns an OPK is an expensive false green.
5. `test/integration/identity-cas.test.ts:25` should not be a pure refusal/no-op check. CAS tests need an accepted CAS in the same setup, otherwise an always-null/no-op implementation passes.
