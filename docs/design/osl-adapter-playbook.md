# OSL Adapter Playbook

Adapters must operate through an authorized, observable target surface; bind
the selected account, recipient, generation, and action; verify the post-action
state; and refuse on ambiguity. Native, browser, and imported adapters carry
the same no-guessing rule and must surface unsupported states honestly.

This is the detailed adapter reference named by the master source index.
