# OSL Enclaves naming

## Binding product name

**Enclaves** is the product name for OSL's channel-bearing community container: the
OSL equivalent of a Discord server. An Enclave contains channels and has membership
and roles.

This is a naming decision, not an availability claim. The current surface remains
`coming_later` until the Enclaves build is complete. Group sender keys from T18 are
a hard prerequisite for that build.

## Superseded names

For this product, do not use **Circles** or **Spaces** in shipping copy, code,
contracts, markup hooks, or test selectors. They are earlier names for the same
channel-bearing container, not separate products.

Historical documents may retain those names when they describe prior decisions.
They must not be treated as current product terminology.

## Naming boundary

This decision does not turn the existing audience fixture into a shipped Enclaves
feature. The fixture is not a real membership model and must be removed as part of
the Enclaves build; the product contract is not made `available` by this rename.

## Authority

This record implements owner decisions D83 and D84 in
`plan/09-DECISIONS.md`. D84 supplies the current noun; D83 remains authoritative
for the Discord-style product definition and its T18 dependency.
