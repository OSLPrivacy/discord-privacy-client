# AutoScrub Architecture

AutoScrub applies bounded unattended cleanup only to a previously approved
scope and stops on limits, challenges, changed content, or failed checks. It
does not make provider-side deletion claims without verification. Per D85,
UNATTENDED is the intended product term.
