Payment help

If checkout closed before completion, no payment was taken and no Pro code was created.

Try checkout again only when you are ready to complete payment, or return to Download OSL Hub.

Payment taken and no code yet

If the money left your account and no Pro code arrived, leave OSL Hub open: the code appears in the app on its own once it is created. Do not pay again, because a second payment takes more money and does not make the first code arrive any sooner.

OSL Hub shows a payment reference on that screen. Keep it: it is the one thing that identifies your payment to us, because OSL never asks for your name or email address. The keyserver re-checks completed payments and creates any missing code by itself, so a code that is late is not a code that is lost.
